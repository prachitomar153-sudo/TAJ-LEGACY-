# Taj Legacy Travel Website

Professional travel and tourism business website developed for showcasing travel services, tour packages, and destination experiences.

## Features

* Responsive website design
* Tour and travel service pages
* Destination showcase sections
* Contact and inquiry forms
* Mobile-friendly layout
* SEO-friendly structure
* Fast loading pages

## Technologies Used

* PHP
* HTML5
* CSS3
* JavaScript

## Purpose

This project was created to provide an engaging online presence for a travel and tourism business and help generate customer inquiries through a professional website experience.
